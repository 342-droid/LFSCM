## 规则说明

本仓库更新日志页由 git 提交生成：标题作整体概述，body 里按页面的说明挂到对应页面明细。

### 标题（必须）

`<type>: <一句业务同事能看懂的中文概述>`

- type：`feat` / `fix` / `refactor` / `style` / `docs` / `chore`
- 写「做了什么事」，不写技术实现

### body（改动涉及页面时必须）

`- <页面中文名>: <这个页面上发生了什么变化，一句人话>`

- 页面中文名用该页 `<title>` 里「 - 」后面的名字
- 面向产品/业务：写界面、交互、流程；不写代码细节
- **弹窗、抽屉、tab 内变化必须写**
- 与具体页面无关可写 `- 通用: …` 或省略
- 同一页面多处变化用「；」连接

## 例外

与页面无关的纯工程改动，body 可省略或只写「通用」。
