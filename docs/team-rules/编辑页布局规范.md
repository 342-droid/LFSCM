## 规则说明

后续新增或改造编辑页 / 配置页，**除非另有说明**，一律遵循：

1. **内容区自适应**：配置内容区域 `width: 100%`，不要写死较窄的 `max-width`（如 760 / 820 / 960 / 1100）；字段控件随屏宽展开。
2. **底栏固定悬浮**：取消 / 保存 / 重置等操作按钮固定在视口底部（侧栏展开收起时同步调整位置）；内容区预留底部内边距，避免被底栏遮挡。
3. **复用公共样式**：引入 `css/lf-mdm-edit-page.css`；`main.main-content` 增加 class `mdm-edit-page`；底栏使用已有 footer class，或统一加 `mdm-edit-page__footer`。
4. **字段行对齐与高度**：整页编辑用 `pts-rule-card` / `pts-rule-field` / `erp-input` / `erp-select`（引入 `css/lf-mdm-points-rule.css`）。标签 168px 右对齐、与 36px 高的输入框垂直对齐。单选/勾选用 `pts-rule-check-row`。不要把弹窗里的 `mkt-tpl-row`、裸 input（32px）套到整页编辑页。

## 例外

仅当明确要求「弹窗编辑」「窄版表单」「底栏随内容滚动」等时，可不按本规范。
