## 1. 需求描述

### 1.1 供应链-主数据，商品品牌

维护供应链商品可用的品牌档案，支持查询、新增、编辑、启用/停用、删除。品牌名称在基础商品库新增商品时作为下拉选项。

原型页面：`SCM/master_data_product_brand.html`

### 1.2 逻辑说明

#### 1.2.1 列表与查询

- 顶部标题「商品品牌」，按钮「+ 新增品牌」
- 查询条件
  - 品牌名称：模糊匹配，不区分大小写
  - 状态：全部、启用、停用
- 按钮：查询、重置；重置清空条件并回到第 1 页
- 列表列：品牌名称、品牌 logo、状态、操作
  - logo：有图展示缩略图，无图展示「无」
  - 状态标签：启用、停用
  - 操作：编辑、停用或启用、删除
- 分页：共 N 条；每页 20 / 50 / 100；页码、上一页、下一页、前往指定页
- 空态
  - 无任何品牌：暂无品牌
  - 有查询条件但无结果：暂无符合条件的品牌

#### 1.2.2 新增 / 编辑品牌

- 弹窗标题：新增品牌、编辑品牌
- 字段
  - 品牌名称：必填，最多 30 字
    - 为空提示「请输入品牌名称」
    - 全库重名提示「品牌名称已存在」；编辑时不含自己
  - 品牌 logo：选填
    - 支持 JPG、PNG、WEBP、GIF、SVG，不超过 2MB
    - 格式不符提示「请上传 JPG、PNG、WEBP、GIF 或 SVG 图片」
    - 超过 2MB 提示「图片不能超过 2MB」
    - 已上传可清除
- 新增保存成功：状态默认启用，提示「品牌已创建」，列表跳到末页展示新数据
- 编辑保存成功：提示「品牌已更新」
- 取消、关闭、点击遮罩：关闭弹窗，不保存

#### 1.2.3 启用 / 停用

- 当前启用：操作「停用」，成功提示「品牌已停用」
- 当前停用：操作「启用」，成功提示「品牌已启用」
- 删除、停用时不做「是否已被商品引用」校验

#### 1.2.4 删除品牌

- 温馨提示：确定删除品牌「名称」？
- 取消、关闭、遮罩：关闭弹窗，什么也不做
- 确定：删除并提示「品牌已删除」

#### 1.2.5 与基础商品库的关系

- 基础商品库查询条件「品牌」：列出全部品牌名称（含停用）
- 新增 / 编辑商品时品牌下拉：仅启用品牌；若编辑商品当前品牌已停用，仍保留该选项以便保存
