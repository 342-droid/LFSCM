## 1. 需求描述

### 1.1 供应链-主数据，配料类别

维护配料表所用的类别字典，支持查询、新增、编辑、启用/停用、删除。基础商品库商品详情「配料表」新增配料时，从启用类别中选择。

原型页面：`SCM/master_data_ingredient_category.html`

### 1.2 逻辑说明

#### 1.2.1 列表与查询

- 顶部标题「配料类别」，按钮「+ 新增类别」
- 查询条件
  - 类别名称：模糊匹配，不区分大小写
  - 状态：全部、启用、停用
- 按钮：查询、重置；重置清空条件并回到第 1 页
- 列表列：类别名称、状态、操作
  - 状态标签：启用、停用
  - 操作：编辑、停用或启用、删除
- 分页：共 N 条；每页 20 / 50 / 100；页码、上一页、下一页、前往指定页
- 空态
  - 无任何类别：暂无类别
  - 有查询条件但无结果：暂无符合条件的类别

#### 1.2.2 新增 / 编辑类别

- 弹窗标题：新增类别、编辑类别
- 字段
  - 类别名称：必填，最多 20 字
    - 为空提示「请输入类别名称」
    - 全库重名提示「类别名称已存在」；编辑时不含自己
- 新增保存成功：状态默认启用，提示「类别已创建」，列表跳到末页展示新数据
- 编辑保存成功：提示「类别已更新」
- 取消、关闭、点击遮罩：关闭弹窗，不保存

#### 1.2.3 启用 / 停用

- 当前启用：操作「停用」，成功提示「类别已停用」
- 当前停用：操作「启用」，成功提示「类别已启用」
- 基础商品库配料表下拉仅展示启用中的类别；编辑配料时若当前类别已停用，仍保留该选项

#### 1.2.4 删除类别

- 温馨提示：确定删除类别「名称」？
- 取消、关闭、遮罩：关闭弹窗，什么也不做
- 确定：删除并提示「类别已删除」
- 删除时不做「是否已被配料引用」校验
