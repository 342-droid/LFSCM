## 1. 需求描述

### 1.1 供应链-主数据，供货关系

维护「货号 × 供应商」的供货关系。一行对应一个货号和一个供应商；同一货号可有多家供应商，同一对不可重复；同一货号最多一个主供应商。货号与标准采购价、标准采购单位等来自基础商品库。

原型页面：`SCM/master_data_supply.html`

### 1.2 逻辑说明

#### 1.2.1 列表与查询

- 顶部标题「供货关系」，按钮「+ 新增供货关系」
- 查询条件
  - SPU编码、货号、货品名称、货品条码、供应商：文本模糊匹配
  - 经营方式：全部、代采代销、购销、联营
  - 价格状态：全部、未核价、已核价
  - 样品状态：全部、待检、合格、无需样品
  - 状态：全部、启用、停用
- 按钮：查询、重置；重置清空条件并回到第 1 页
- 列表列：供应商编码、供应商、货品名称、SPU编码、货号、货品条码、保质期、温层、商品图片、经营方式、标准采购价、标准采购单位、采购核定价、实际采购单位、最小起订量、价格状态、样品状态、是否主供应商、状态、操作
  - 经营方式、标准采购价、标准采购单位优先取基础商品库实时值
  - 是否主供应商：是 / 否
  - 操作：编辑、停用或启用、删除
- 默认排序：货号升序 → 主供应商优先 → 供应商名称
- 分页：共 N 条；每页 20 / 50 / 100；页码、上一页、下一页、前往指定页
- 空态
  - 无任何关系：暂无供货关系
  - 有查询条件但无结果：暂无符合条件的供货关系

#### 1.2.2 新增 / 编辑供货关系

- 弹窗标题：新增供货关系、编辑供货关系
- 商品信息区
  - 新增：货号必选下拉（来自基础商品库有货号的商品）；选中后带出 SPU、条码、保质期、温层、经营方式、标准采购价、标准采购单位等只读信息
  - 编辑：货号、供应商只读，不可改配对
  - 未选货号时商品区为空态文案「请先选择货号」
- 供货信息字段
  - 供应商：新增必选；下拉为启用供应商，若当前供应商已停用仍可展示并标注「（已停用）」；未选提示「请选择供应商」
  - 供应商编码：随供应商自动带出，只读
  - 采购核定价：必填，大于等于 0；为空或不合法提示「请输入采购核定价」
  - 实际采购单位：必填；选项受商品所属一级分类的「商品单位」配置约束（见商品分类 PRD）；未选提示「请选择实际采购单位」
  - 最小起订量：必填，大于等于 1 的整数；不合法提示「请输入最小起订量」
  - 价格状态：必填，未核价 / 已核价；默认未核价；未选提示「请选择价格状态」
  - 样品状态：必填，待检 / 合格 / 无需样品；默认待检；未选提示「请选择样品状态」
  - 状态：启用 / 停用；新增默认启用
  - 主供应商：勾选「设为主供应商」；勾选保存后，同一货号下其他关系的主供应商标记取消
- 校验顺序补充
  - 未选货号：「请选择货号」
  - 同一货号 + 同一供应商已存在：「该货号已存在此供应商的供货关系」（仅新增）
  - 所选货号缺少经营方式：「所选货号缺少经营方式」
  - 所选货号缺少标准采购价：「所选货号缺少标准采购价」
- 切换货号时，实际采购单位下拉按新商品所属一级分类刷新；若原选单位仍在可选范围内则保留
- 新增保存成功：提示「供货关系已创建」
- 编辑保存成功：提示「供货关系已更新」
- 取消、关闭、点击遮罩：关闭弹窗，不保存

#### 1.2.3 启用 / 停用

- 当前启用：操作「停用」，成功提示「供货关系已停用」
- 当前停用：操作「启用」，成功提示「供货关系已启用」

#### 1.2.4 删除供货关系

- 温馨提示：确定删除货号「货号」与供应商「供应商名称」的供货关系？
- 取消、关闭、遮罩：关闭弹窗，什么也不做
- 确定：删除并提示「供货关系已删除」

#### 1.2.5 与基础商品库 / 商品分类的关系

- 货号、标准采购价、标准采购单位、经营方式等以基础商品库为准，本页只读展示
- 实际采购单位：一级分类已配置商品单位时仅可选配置项；未配置时用供应链全局单位枚举
- 商品详情中的「供货关系」页签只读展示本页数据，不在详情内新增关系
