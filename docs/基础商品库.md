## 1. 需求描述

### 1.1 供应链-主数据，基础商品库

在四级分类下维护基础商品。左侧仅按一级分类筛选，右侧查询与列表；新增商品时在弹窗内选择该一级下的四级分类。支持添加规格、启用/停用、商品详情（含图文、配料表、营养成分、供货关系只读），以及编辑标准采购价。单位选项受所属一级分类「商品单位」配置约束；表单字段受所属一级「字段模型」约束。

原型页面：`SCM/master_data_product_library.html`

### 1.2 逻辑说明

#### 1.2.1 分类筛选

- 左侧仅一列：一级分类；提示「按一级筛选商品；新增时再选四级分类」
- 可点「全部」清空一级选中
- 分类卡片：图标或名称首字、名称、显示/隐藏标签、商品数
- 右侧列表：未选一级时展示全部已挂四级的商品；选中一级则展示该一级及下级汇总商品
- 切换分类清空字段筛选并关闭相关弹窗；进入页面不默认选中分类
- 「+ 新增商品」仅在选中一级时可点；未选禁用，悬停「请先选择一级分类」；若仍触发，提示「请先选择一级分类」
- 新增弹窗须选择该一级下的四级分类；未选提示「请选择四级分类」；无四级时提示「该一级下暂无四级分类」

#### 1.2.2 查询与列表

- 页签：基础商品库
- 顶部统计：商品数量、商品条码数量
- 查询条件
  - 商品分类：级联选择二 / 三 / 四级（选项范围随左侧当前一级）；未选一级时禁用，提示「请先选择一级分类」；可清空调回一级范围；点「查询」后按所选节点及下级筛商品
  - 其余（模糊）：SPU编码、货号、商品条码、商品名称；商品状态（全部 / 启用 / 停用）；品牌（全部 + 品牌库全部名称）
- 按钮：查询、重置（重置同时清空商品分类）；另有「字段筛选」
- 列表列：SPU编码、货号（点击打开详情）、商品条码、商品图片、商品名称、商品状态、品牌、标准采购价、标准采购单位、最小单位、规格单位、包装单位、操作
- 操作：添加规格、停用或启用（列表无编辑、删除）
- 空态：无查询条件时「该分类下暂无商品」；有查询条件时「暂无符合条件的商品」
- 分页：共 N 条；每页 20 / 50 / 100

#### 1.2.3 字段筛选

- 未选分类提示「请先选择分类」
- 弹窗标题「字段筛选」；按所属一级「字段模型」扩展字段筛选当前分类下商品
- 按分组分块展示；字段旁标注类型；无字段：「该分类所属一级暂无扩展字段」
- 控件与类型一致：下拉→下拉框；单选→单选；多选→勾选；开关→开关；文本/多行文本/数字/整数/日期→对应输入
- 文本类按包含匹配；多选同一字段多值取「或」，不同字段取「且」
- 确定后列表上方展示筛选标签，可单删或「清除」；取消弹窗不生效

#### 1.2.4 新增 / 编辑商品

- 入口
  - 新增：选中一级后点「+ 新增商品」，弹窗内再选四级分类
  - 编辑：商品详情内点编辑
  - 添加规格：列表「添加规格」
- 弹窗标题：添加商品、编辑商品
- 新增时首项为「四级分类」下拉（当前一级下全部四级，展示完整路径）；选定后生成 SPU / 货号并刷新扩展字段与单位选项
- 字段来源：由四级溯源到一级，读取一级「字段模型」决定扩展字段与系统字段的显示/必填
- 扩展字段区：按一级字段模型的分组分块展示；无字段「所属一级字段模型暂无扩展字段」
  - 下拉 / 单选 / 多选：选项为模型配置的 options；多选值用顿号拼接保存；必填未选提示「请选择字段名」
  - 开关：是 / 否；始终有值，必填时不单独拦截
  - 文本 / 多行文本 / 数字 / 整数 / 日期：对应输入框；整数须为整型；必填未填提示「请填写字段名」
  - 有说明时在控件下方展示 tip
- 固定商品信息字段（始终显示且必填）
  - SPU编码：只读系统生成，格式 `SPU` + 一级两位编码 + 4 位流水；添加规格 / 编辑沿用原 SPU；用尽提示「该分类SPU编码已用完」
  - 货号：只读，一级两位编码 + 4 位流水，同分类不重复；用尽提示「该分类货号已用完」
  - 商品名称：必填；为空提示「请输入商品名称」
  - 商品条码：必填；为空提示「请输入商品条码」
  - 商品品牌：必填，仅启用品牌（当前已停用品牌编辑时仍可保留）；未选提示「请选择商品品牌」
  - 标准采购价：必填，大于等于 0；为空或不合法提示「请输入标准采购价」
  - 标准采购单位：必填；选项见 1.2.8；未选提示「请选择标准采购单位」
- 可配系统字段（由一级字段模型控制显示与必填；隐藏时不渲染、不校验，编辑时保留历史值）
  - 保质期天数：大于等于 0；必填时为空或不合法提示「请输入保质期天数」
  - 经营方式：代采代销 / 购销 / 联营；必填时未选提示「请选择经营方式」
  - 是否称重：是 / 否；必填时未选提示「请选择是否称重」
  - 温层：常温 / 冷藏 / 冷冻；必填时未选提示「请选择温层」
  - 单位换算卡片：见下；模型关闭时不展示，保存保留历史单位数据
  - 图文信息：见下；模型关闭时不展示，保存保留历史文案
- 单位换算卡片（四级；模型开启「单位换算」时展示）
  - 1 最小计量单位：换算单位可自选
  - 2 最小单位：换算单位锁定跟随最小计量单位
  - 3 规格单位：换算单位锁定跟随最小单位
  - 4 包装单位：换算单位锁定跟随规格单位
  - 每级：本级单位、换算「1 X = 数量 Y」、毛重 / 皮重 / 净重（kg）、长宽高（cm）、体积（m³，只读，长×宽×高自动算）
  - 净重可手改；未手改时等于毛重减皮重；换算数量非必填
  - 单位下拉受一级分类商品单位配置约束
- 图文信息（模型开启「图文信息」时展示，非必填）：卖点、产品基本信息介绍、其他功能与操作事项、场景带入、售后服务、图文详情；商品图片 / 视频入口提示「原型暂未开放该操作」
- 新增保存成功：默认启用，提示「商品已添加」，并同步分类商品数；编辑成功提示「商品已更新」
- 取消、关闭、点击遮罩：关闭弹窗，不保存

#### 1.2.5 添加规格

- 基于已有商品，生成新货号，归属同一 SPU；基础字段可预填，单位卡按当前分类单位范围重新默认
- 弹窗标题为「添加商品」；保存后作为同 SPU 下新规格进入列表

#### 1.2.6 商品详情

- 入口：点击列表货号；标题「商品详情」
- 顶部：商品名称旁「编辑」打开编辑弹窗；标准采购价旁「编辑」打开改价弹窗
- 标签区：属性值、换算文案、单位 / 净重 / 称重等；无标签「暂无标签」
- 页签
  - 商品信息：按一级字段模型展示系统字段；模型已关闭但历史有值的字段仍展示；单位换算在模型开启或历史有单位数据时展示
  - 图文信息：模型开启或历史有文案时展示；六个文案字段只读，空为「—」
  - 配料表：见 1.2.9
  - 营养成分：见 1.2.10
  - 供货关系：只读，见 1.2.11
- 关闭详情后回到列表

#### 1.2.7 编辑标准采购价

- 详情价区或入口打开弹窗「编辑标准采购价」
- 标准采购价：必填；为空提示「请输入标准采购价」
- 标准采购单位：必填；选项同新增商品，受一级分类单位配置约束；未选提示「请选择标准采购单位」
- 保存成功提示「标准采购价已更新」，并刷新详情

#### 1.2.8 商品单位可选范围

- 取商品所属四级分类对应的一级分类
- 该一级已在「商品单位」页签配置至少 1 个单位：标准采购单位及四级单位换算下拉仅可选这些单位
- 未配置：使用供应链全局单位枚举（箱、件、垛、提…单，与商品分类 PRD 一致）
- 编辑时若历史单位不在当前可选范围，临时保留展示，便于改选

#### 1.2.9 配料表

- 详情「配料表」页签；按钮「复制配料」「+ 新增配料」
- 列表列：序号、配料名称、配料类别、参考占比（约 x%）、过敏原提示、资料来源、编辑 / 删除
- 空态：「暂无配料」；配料分页默认每页 200 条，可选 20 / 50 / 100 / 200
- 新增 / 编辑字段
  - 配料名称：必填，最多 40 字；为空「请输入配料名称」；同货号重名「配料名称已存在」
  - 配料类别：必填，选项为启用中的配料类别（当前已停用仍可保留）；未选「请选择配料类别」
  - 参考占比：必填，大于 0 且不超过 100；不符「参考占比请填写大于 0 且不超过 100 的数字」
  - 过敏原提示：必填，选项为无、含麸质的谷物、含大豆及其制品、含乳及乳制品、含蛋类、含花生及其制品、含鱼类、含甲壳类、含芝麻；未选「请选择过敏原提示」；默认「无」
  - 资料来源：必填，最多 40 字；为空「请输入资料来源」
- 保存提示「配料已添加」或「配料已更新」；删除温馨提示「确定删除配料「名称」？」→「配料已删除」
- 复制配料
  - 仅可选同 SPU 其他货号；说明：复制后覆盖当前商品已有配料
  - 同 SPU 无其他货号：「同SPU下暂无其他货号」，确定按钮禁用
  - 未选来源「请选择来源货号」；来源无配料「该货号暂无配料」；成功「配料已复制」

#### 1.2.10 营养成分

- 详情「营养成分」页签；营养标示可选「每100g」「每100ml」（默认每100g），表头含量列随标示变化
- 按钮「复制营养成分」「+ 新增营养成分」
- 列表列：序号、营养项目、{标示}含量、NRV%、检测方法、数据来源；空态「暂无营养成分」
- 新增 / 编辑字段
  - 营养项目：必填，最多 20 字；为空「请输入营养项目」；同货号重名「营养项目已存在」
  - 含量：必填，最多 20 字；为空「请输入含量」
  - NRV%：必填，大于等于 0；不符「NRV%请填写大于等于 0 的数字」
  - 检测方法：必填，最多 30 字；为空「请输入检测方法」
  - 数据来源：必填，最多 30 字；为空「请输入数据来源」
- 保存提示「营养成分已添加」或「营养成分已更新」；删除温馨提示「确定删除营养项目「名称」？」→「营养成分已删除」
- 复制规则同配料表，文案对应营养成分；成功「营养成分已复制」

#### 1.2.11 供货关系（只读）

- 按当前货号展示供货关系；主供应商优先，再按供应商名称排序
- 列：供应商编码、供应商、采购核定价、实际采购单位、最小起订量、价格状态、样品状态、是否主供应商、状态
- 顶部：共 N 条供货关系；无数据「暂无该商品的供货关系」
- 本页不增删改供货关系，维护入口在「供货关系」菜单

#### 1.2.12 启用 / 停用

- 列表操作切换商品状态；无删除商品入口
- 成功提示「商品已停用」或「商品已启用」
