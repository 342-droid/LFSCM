## 1. 需求描述

### 1.1 供应链-主数据，商品分类

从左到右维护一级、二级、三级、四级分类。商品只挂在四级分类。选中某一级后，右侧展示该分类详情，可维护分类信息、商品单位、属性分类、商品属性，四级分类还可查看已绑定商品。

原型页面：`SCM/master_data_product_category.html`

### 1.2 逻辑说明

#### 1.2.1 分类级联

- 页面从左到右四列：一级分类、二级分类、三级分类、四级分类；最右侧为分类详情
- 一级列提示：从左到右依次维护
- 未选上级时
  - 二级提示：请先选择一级分类
  - 三级提示：请先选择二级分类
  - 四级提示：请先选择三级分类
- 已选上级时，提示改为所属路径
  - 二级：所属：一级名称
  - 三级：所属：一级名称 / 二级名称
  - 四级：所属：一级名称 / 二级名称 / 三级名称
- 新增按钮
  - 一级：始终可点
  - 二级：未选一级时禁用；点击时若仍无一级，提示「请先选择一级分类」
  - 三级：未选二级时禁用；点击时若仍无二级，提示「请先选择二级分类」
  - 四级：未选三级时禁用；点击时若仍无三级，提示「请先选择三级分类」
- 列表按排序从小到大排列
- 分类卡片
  - 分类图标：有图标展示图标，无图标展示名称首字
  - 分类名称
  - 状态标签：显示、隐藏
  - 商品数
    - 四级：该分类已绑定商品个数
    - 一级、二级、三级：其全部下级商品数汇总
- 空态
  - 一级无数据：暂无一级分类
  - 未选一级：请先选择一级分类；已选但无二级：该一级下暂无二级分类
  - 未选二级：请先选择二级分类；已选但无三级：该二级下暂无三级分类
  - 未选三级：请先选择三级分类；已选但无四级：该三级下暂无四级分类
- 点击某一级卡片：选中该分类，并清空其下级的选中；右侧详情切到被点击的分类
- 进入页面时不默认选中任何分类

#### 1.2.2 新增 / 编辑分类

- 新增弹窗标题：新增一级分类、新增二级分类、新增三级分类、新增四级分类
- 编辑弹窗标题：编辑分类
- 说明文案
  - 新增一级：请完整填写分类信息。
  - 新增二级及以下：将在「上级路径」下创建对应级别分类
  - 编辑：编辑「完整路径」
- 新增二级及以下时，只读展示已选的各级所属分类名称，不可改上级
- 字段
  - 分类编码：必填，系统生成，只读
    - 同级按已有编码段取最大值后 +1，两位数字，从 10 起，最大 99
    - 完整编码 = 上级完整编码 + 本级两位编码；一级没有上级，完整编码即本级两位编码
    - 同级编码用尽时，确定提示「同级分类编码已用完」，不保存
    - 新增时同级已有相同编码段，提示「同级下已存在相同分类编码」
    - 创建后不可修改
  - 分类名称：必填
    - 为空提示「请输入分类名称」
    - 同级已有相同名称，提示「同级下已存在同名分类」
    - 比较范围为同一上级下的分类；编辑时不含自己
  - 分类图标：必填
    - 支持 JPG、PNG、WEBP、SVG，建议正方形，单张不超过 2MB
    - 格式不符提示「请上传 JPG/PNG/WEBP/SVG 格式图片」
    - 超过 2MB 提示「图片不能超过 2MB」
    - 未上传点确定，提示「请上传分类图标」
  - 排序：必填，大于等于 0 的整数
    - 为空或小于 0，提示「请输入排序」
    - 同级已有相同排序，提示「同级下已存在相同排序」
- 新增保存成功
  - 状态默认显示
  - 四级标记为商品挂载点，一至三级不是挂载点
  - 选中新建分类，并清空更深层级的选中
  - 提示「分类已创建」
- 编辑保存成功
  - 可改名称、图标、排序；编码与上级不变
  - 名称变更后，本级及全部下级的完整路径同步更新
  - 提示「分类已更新」
- 取消、关闭、点击遮罩：关闭弹窗，不保存

#### 1.2.3 分类详情-分类信息

- 未选分类
  - 路径展示：请选择分类
  - 内容展示：从左侧选择一级至四级分类
  - 商品单位、属性分类、商品属性、已绑定商品页签不展示
- 已选分类，路径按「一级 / 二级 / 三级 / 四级」展示，当前分类高亮
- 页签
  - 分类信息：各级都有
  - 商品单位：仅一级分类展示；切到非一级时，若当前停在该页签，回到分类信息
  - 属性分类：仅一级分类展示；切到非一级时，若当前停在该页签，回到分类信息
  - 商品属性：各级都有
  - 已绑定商品：仅四级分类展示；切到非四级时，若当前停在该页签，回到分类信息
- 分类信息展示
  - 图标、分类名称
  - 级别：一级分类、二级分类、三级分类、四级分类；四级追加「（商品挂载点）」
  - 状态标签：显示、隐藏
  - 分类编码：完整编码
  - 完整路径
  - 排序
  - 已绑定商品：N 个；一至三级追加「（下级汇总）」
  - 创建时间
- 操作：编辑、显示或隐藏、删除

#### 1.2.4 商品单位

- 仅一级分类可维护；该一级下全部下级的新增商品、供货关系，单位下拉都受此配置约束
- 单位从供应链全局枚举中选择，枚举固定为：箱、件、垛、提、瓶、罐、盒、ml、袋、包、克、颗、kg、斤、筐、个、只、尾、桶、片、泵瓶、支、卷、条、双、副、台、套、块、平方米、本、册、张、粒、棵、次、单
- 列表按排序从小到大
- 顶部：共 N 个商品单位；按钮「新增单位」
- 说明：单位从供应链全局枚举中选择；配置后对该一级分类下全部下级生效。
- 无数据：暂无商品单位；配置后，本一级下新增商品与供货关系仅可选这些单位
- 每行：单位名称、排序、编辑、删除
- 新增 / 编辑弹窗
  - 标题：新增商品单位、编辑商品单位
  - 说明：维护一级分类「名称」的商品单位。配置后，该一级下新增商品与供货关系仅可选这些单位。
  - 单位：必填，下拉为全局枚举中尚未添加的单位（编辑时可保留当前值）；未选提示「请选择单位」；全部已添加时点新增提示「全局枚举中的单位已全部添加」
  - 排序：必填，大于等于 0 的整数；为空或小于 0 提示「请输入排序」；同一一级下排序重复提示「同级下已存在相同排序」；同一一级下单位重复提示「该单位已添加」
  - 保存成功提示「商品单位已新增」或「商品单位已更新」
  - 取消、关闭、点击遮罩：关闭弹窗，不保存
- 删除
  - 温馨提示：确定删除商品单位「名称」？
  - 取消：关闭弹窗，什么也不做
  - 确定：删除并提示「商品单位已删除」
- 联动规则
  - 一级分类已配置至少 1 个单位：基础商品库新增/编辑商品、编辑标准采购价，以及供货关系的实际采购单位，仅允许选择这些单位
  - 一级分类未配置任何单位：回退使用全局枚举全量
  - 编辑历史数据时，若当前已存单位不在可选范围内，仍临时展示该值，便于核对后再改

#### 1.2.5 显示 / 隐藏

- 当前为显示：按钮为「隐藏」
  - 点击后该分类变为隐藏，提示「分类已隐藏」
  - 一至三级被隐藏时，其全部下级同步变为隐藏
- 当前为隐藏：按钮为「显示」
  - 任一上级仍为隐藏：按钮禁用，悬停提示「上级分类已隐藏，请先显示上级分类」；若仍触发，同样提示，不改变状态
  - 上级均为显示：点击后仅本级变为显示，提示「分类已显示」；已隐藏的下级不会自动变为显示，需逐级打开
- 列表中隐藏分类仍可见，并带隐藏标签

#### 1.2.6 删除分类

- 本级或任一下级仍绑定商品：删除按钮禁用，悬停提示「分类及下级分类已关联商品，请先解除绑定后再操作」；若仍触发，同样提示，不删除
- 可删除时弹出温馨提示
  - 存在下级：删除「分类名称」将同时删除其下 N 个下级分类，确定继续？N 为全部下级个数
  - 无下级：确定删除分类「分类名称」？
  - 点击取消、关闭、遮罩：关闭弹窗，什么也不做
  - 点击确定：删除本级及全部下级，提示「分类已删除」；若当前选中落在被删分类上，清空对应选中

#### 1.2.7 属性分类

- 仅一级分类可维护；该一级下的二、三、四级商品属性，都从这里选择属性分类
- 列表按排序从小到大
- 顶部：共 N 个属性分类；按钮「新增属性分类」
- 无数据：暂无属性分类
- 每行：属性分类名称、排序、编辑、删除
- 新增 / 编辑弹窗
  - 标题：新增属性分类、编辑属性分类
  - 说明：维护一级分类「名称」的属性分类。下级分类的商品属性从这里选择。
  - 属性分类：必填；为空提示「请输入属性分类」；同一一级下重名提示「已存在同名属性分类」
  - 排序：必填，大于等于 0 的整数；为空或小于 0 提示「请输入排序」；同一一级下排序重复提示「同级下已存在相同排序」
  - 保存成功提示「属性分类已新增」或「属性分类已更新」
  - 取消、关闭、点击遮罩：关闭弹窗，不保存
- 删除
  - 该一级及其下级任一商品属性仍引用此属性分类：不弹确认，提示「该属性分类下已有商品属性，请先调整后再删除」
  - 未被引用：温馨提示「确定删除属性分类「名称」？」
    - 取消：关闭弹窗，什么也不做
    - 确定：删除并提示「属性分类已删除」

#### 1.2.8 商品属性

- 各级分类都可维护本级属性
- 展示范围：从一级到当前分类，逐级带出属性
  - 上级属性标记「继承自一级分类 / 二级分类 / 三级分类」，编辑、删除禁用，悬停「继承自对应级别分类，不可操作」
  - 本级属性可编辑、可删除
- 分组：按所属一级的属性分类排序展示；分组标题含属性分类名称、排序、属性个数
  - 分组下无属性：暂无商品属性
  - 属性的属性分类对不上任一分组：归入「未分类」，该组不展示排序
  - 没有任何属性分类且没有属性：暂无商品属性
- 顶部：共 N 个属性（含继承）；按钮「新增属性」
- 属性行
  - 属性名称、排序
  - 属性值：无下级时以标签展示；某一属性值下还有下级属性时，按分支展开下级属性名称和属性值
  - 未设置属性值时展示「未设置」
- 新增 / 编辑弹窗
  - 标题：新增属性、编辑属性
  - 说明：维护「当前分类名称」的商品属性。属性值下可继续添加下级属性，最多 5 级。
  - 所属一级还没有属性分类时，追加说明：请先在一级分类「一级名称」的属性分类页签中维护属性分类。
  - 属性分类：必填，下拉为所属一级已维护的属性分类；未选提示「请选择属性分类」
  - 属性名称：必填；为空提示「请输入属性名称」
    - 从一级到当前分类的路径上已有同名属性（含继承），提示「已存在同名属性」；编辑时不含自己
  - 排序：必填，大于等于 0 的整数；为空或小于 0 提示「请输入排序」
    - 仅与当前分类自己的属性比排序，继承来的属性不参与；重复提示「同级下已存在相同排序」
  - 属性值：必填，至少一条
    - 为空提示「请输入属性值」
    - 同一层属性值不能重复，重复提示「属性值不能重复」
    - 「+」在当前值后追加一条；「−」删除当前值
    - 只剩一条且内容为空时，「−」禁用
    - 只剩一条且已有内容时，「−」清空该值及其下级属性，不删掉这一行
  - 下级属性：每个属性值可继续添加下一级，按钮文案为二级属性、三级属性、四级属性、五级属性；第五级不能再往下加
    - 下级需填写属性名称、属性值，规则与上面相同
    - 属性名称为空：提示「请输入对应级别属性名称」，如「请输入二级属性名称」
    - 同一属性值下的同级下级属性名称不能重复，提示「二级属性名称不能重复」（级别随当前层变化）
  - 保存成功提示「属性已新增」或「属性已更新」
  - 取消、关闭、点击遮罩：关闭弹窗，不保存
- 删除本级属性
  - 温馨提示：确定删除属性「属性名称」？
  - 取消：关闭弹窗，什么也不做
  - 确定：删除并提示「属性已删除」
  - 继承属性不可删除

#### 1.2.9 已绑定商品

- 仅四级分类展示该页签
- 顶部：共 N 个商品
- 商品卡片：商品图片、商品名称、商品编码
- 无数据：暂无绑定商品；删除分类前需解绑全部商品
- 本页只查看已绑定商品，不在本页绑定或解绑；解绑完成后，才允许删除对应分类
