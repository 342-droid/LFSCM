## 1. 需求描述

### 1.1 供应链-主数据，商品分类

从左到右维护一级、二级、三级、四级分类。商品只挂在四级分类。选中某一级后，右侧展示该分类详情；一级可维护分类信息、商品单位、字段模型，四级还可查看已绑定商品。字段模型决定该一级下新增商品时展示哪些系统字段与扩展字段。

原型页面：`SCM/master_data_product_category.html`

### 1.2 逻辑说明

#### 1.2.1 分类级联

- 页面从左到右四列：一级分类、二级分类、三级分类、四级分类；最右侧为分类详情
- 一级列提示：拖动排序仅当前账号生效
- 未选上级时
  - 二级提示：请先选择一级分类
  - 三级提示：请先选择二级分类
  - 四级提示：请先选择三级分类
- 已选上级时，提示改为所属路径
  - 二级：所属：一级名称
  - 三级：所属：一级名称 / 二级名称
  - 四级：所属：一级名称 / 二级名称 / 三级名称
- 新增按钮
  - 一级：始终可点
  - 二级：未选一级时禁用；点击时若仍无一级，提示「请先选择一级分类」
  - 三级：未选二级时禁用；点击时若仍无二级，提示「请先选择二级分类」
  - 四级：未选三级时禁用；点击时若仍无三级，提示「请先选择三级分类」
- 列表按排序从小到大排列；若当前账号有个人拖动排序，优先按个人顺序展示
- 拖动排序
  - 同一上级下的同级分类支持手动拖动调整顺序（一至四级各自独立）
  - 同级多于 1 条时，卡片左侧显示拖动手柄；拖到目标位置松手后保存，提示「排序已更新（仅当前账号）」
  - 拖动后的顺序仅对当前登录账号生效，不影响其他账号，也不改写主数据全局排序
  - 一级列提示：拖动排序仅当前账号生效
  - 同步范围：当前账号调整分类顺序后，基础商品库页须同步采用同一套账号顺序
    - 左侧一级分类列表：与商品分类页一级列顺序一致
    - 查询区「商品分类」选择页（二 / 三 / 四级级联）：与商品分类页对应同级顺序一致
    - 上述同步同样仅对当前账号生效；其他账号仍看各自顺序或主数据默认序
- 分类卡片
  - 分类图标：有图标展示图标，无图标展示名称首字
  - 分类名称
  - 状态标签：显示、隐藏
  - 商品数
    - 四级：该分类已绑定商品个数
    - 一级、二级、三级：其全部下级商品数汇总
- 空态
  - 一级无数据：暂无一级分类
  - 未选一级：请先选择一级分类；已选但无二级：该一级下暂无二级分类
  - 未选二级：请先选择二级分类；已选但无三级：该二级下暂无三级分类
  - 未选三级：请先选择三级分类；已选但无四级：该三级下暂无四级分类
- 点击某一级卡片：选中该分类，并清空其下级的选中；右侧详情切到被点击的分类
- 进入页面时不默认选中任何分类

#### 1.2.2 新增 / 编辑分类

- 新增弹窗标题：新增一级分类、新增二级分类、新增三级分类、新增四级分类
- 编辑弹窗标题：编辑分类
- 说明文案
  - 新增一级：请完整填写分类信息。
  - 新增二级及以下：将在「上级路径」下创建对应级别分类
  - 编辑：编辑「完整路径」
- 新增二级及以下时，只读展示已选的各级所属分类名称，不可改上级
- 字段
  - 分类编码：必填，系统生成，只读
    - 同级按已有编码段取最大值后 +1，两位数字，从 10 起，最大 99
    - 完整编码 = 上级完整编码 + 本级两位编码；一级没有上级，完整编码即本级两位编码
    - 同级编码用尽时，确定提示「同级分类编码已用完」，不保存
    - 新增时同级已有相同编码段，提示「同级下已存在相同分类编码」
    - 创建后不可修改
  - 分类名称：必填
    - 为空提示「请输入分类名称」
    - 同级已有相同名称，提示「同级下已存在同名分类」
    - 比较范围为同一上级下的分类；编辑时不含自己
  - 分类图标：必填
    - 支持 JPG、PNG、WEBP、SVG，建议正方形，单张不超过 2MB
    - 格式不符提示「请上传 JPG/PNG/WEBP/SVG 格式图片」
    - 超过 2MB 提示「图片不能超过 2MB」
    - 未上传点确定，提示「请上传分类图标」
  - 排序：新增/编辑表单不展示；新增时主数据默认排到同级末尾；展示顺序由列表拖动按账号调整
- 新增保存成功
  - 状态默认显示
  - 四级标记为商品挂载点，一至三级不是挂载点
  - 选中新建分类，并清空更深层级的选中
  - 提示「分类已创建」
- 编辑保存成功
  - 可改名称、图标；编码与上级不变；个人排序不在编辑里改
  - 名称变更后，本级及全部下级的完整路径同步更新
  - 提示「分类已更新」
- 取消、关闭、点击遮罩：关闭弹窗，不保存

#### 1.2.3 分类详情-分类信息

- 未选分类
  - 路径展示：请选择分类
  - 内容展示：从左侧选择一级至四级分类
  - 商品单位、属性分类、商品属性、已绑定商品页签不展示
- 已选分类，路径按「一级 / 二级 / 三级 / 四级」展示，当前分类高亮
- 页签
  - 分类信息：各级都有
  - 商品单位：仅一级分类展示；切到非一级时，若当前停在该页签，回到分类信息
  - 字段模型：仅一级分类展示；切到非一级时，若当前停在该页签，回到分类信息（吸收原「属性分类」「商品属性」）
  - 已绑定商品：仅四级分类展示；切到非四级时，若当前停在该页签，回到分类信息
- 分类信息展示
  - 图标、分类名称
  - 级别：一级分类、二级分类、三级分类、四级分类；四级追加「（商品挂载点）」
  - 状态标签：显示、隐藏
  - 分类编码：完整编码
  - 完整路径
  - 排序：展示当前账号下的有效顺序，并标注「（仅当前账号）」
  - 已绑定商品：N 个；一至三级追加「（下级汇总）」
  - 创建时间
  - 二至四级追加说明：扩展字段与可配商品信息由所属一级的字段模型统一维护
- 操作：编辑、显示或隐藏、删除

#### 1.2.4 商品单位

- 仅一级分类可维护；该一级下全部下级的新增商品、供货关系，单位下拉都受此配置约束
- 单位从供应链全局枚举中选择，枚举固定为：箱、件、垛、提、瓶、罐、盒、ml、袋、包、克、颗、kg、斤、筐、个、只、尾、桶、片、泵瓶、支、卷、条、双、副、台、套、块、平方米、本、册、张、粒、棵、次、单
- 列表按排序从小到大
- 顶部：共 N 个商品单位；按钮「新增单位」
- 说明：单位从供应链全局枚举中选择；配置后对该一级分类下全部下级生效。
- 无数据：暂无商品单位；配置后，本一级下新增商品与供货关系仅可选这些单位
- 每行：单位名称、排序、编辑、删除
- 新增 / 编辑弹窗
  - 标题：新增商品单位、编辑商品单位
  - 说明：维护一级分类「名称」的商品单位。配置后，该一级下新增商品与供货关系仅可选这些单位。
  - 单位：必填，下拉为全局枚举中尚未添加的单位（编辑时可保留当前值）；未选提示「请选择单位」；全部已添加时点新增提示「全局枚举中的单位已全部添加」
  - 排序：必填，大于等于 0 的整数；为空或小于 0 提示「请输入排序」；同一一级下排序重复提示「同级下已存在相同排序」；同一一级下单位重复提示「该单位已添加」
  - 保存成功提示「商品单位已新增」或「商品单位已更新」
  - 取消、关闭、点击遮罩：关闭弹窗，不保存
- 删除
  - 温馨提示：确定删除商品单位「名称」？
  - 取消：关闭弹窗，什么也不做
  - 确定：删除并提示「商品单位已删除」
- 联动规则
  - 一级分类已配置至少 1 个单位：基础商品库新增/编辑商品、编辑标准采购价，以及供货关系的实际采购单位，仅允许选择这些单位
  - 一级分类未配置任何单位：回退使用全局枚举全量
  - 编辑历史数据时，若当前已存单位不在可选范围内，仍临时展示该值，便于核对后再改

#### 1.2.5 显示 / 隐藏

- 当前为显示：按钮为「隐藏」
  - 点击后该分类变为隐藏，提示「分类已隐藏」
  - 一至三级被隐藏时，其全部下级同步变为隐藏
- 当前为隐藏：按钮为「显示」
  - 任一上级仍为隐藏：按钮禁用，悬停提示「上级分类已隐藏，请先显示上级分类」；若仍触发，同样提示，不改变状态
  - 上级均为显示：点击后仅本级变为显示，提示「分类已显示」；已隐藏的下级不会自动变为显示，需逐级打开
- 列表中隐藏分类仍可见，并带隐藏标签

#### 1.2.6 删除分类

- 本级或任一下级仍绑定商品：删除按钮禁用，悬停提示「分类及下级分类已关联商品，请先解除绑定后再操作」；若仍触发，同样提示，不删除
- 可删除时弹出温馨提示
  - 存在下级：删除「分类名称」将同时删除其下 N 个下级分类，确定继续？N 为全部下级个数
  - 无下级：确定删除分类「分类名称」？
  - 点击取消、关闭、遮罩：关闭弹窗，什么也不做
  - 点击确定：删除本级及全部下级，提示「分类已删除」；若当前选中落在被删分类上，清空对应选中

#### 1.2.7 字段模型

- 仅一级分类可维护；配置挂在本一级上，类目间互不影响；该一级下全部下级的新增/编辑商品、属性筛选都消费此模型
- 页签展示形态参考「字段模型与一级类目绑定」：
  - 标题：字段模型与一级类目绑定
  - 绑定信息：绑定的一级类目「编码 名称」；标签「通用字段 N」「专属字段 M」
  - 操作：从其他一级复制、新增分组、新增扩展字段
  - 分区表格列：字段、标识、类型、必填、说明、操作
  - 底部汇总：「名称模型共 N 个字段」
- 复制
  - 弹窗选择来源一级（不含自己）；未选提示「请选择来源一级分类」；无其他一级时确定禁用
  - 确认后深拷贝覆盖本一级当前系统字段与扩展字段配置，提示「字段模型已复制」
- 通用字段（系统字段）
  - 分区标题「通用字段」；表内展示当前已显示字段
  - 列：字段名、标识（key）、类型（文本/下拉/数字/区块）、必填标签（红「必填」/灰「选填」）、说明、操作
  - 固定字段操作列显示「固定」，不可隐藏、始终必填：商品名称、SPU编码、货号、商品条码、商品品牌、标准采购价、标准采购单位
  - 可配字段：保质期天数、经营方式、是否称重、温层、单位换算、图文信息；点击必填标签切换必填/选填；操作「隐藏」后收入「已隐藏的通用字段」可再「显示」
  - 变更即保存，提示「系统字段已更新」；一级未单独配置时按字段池默认回退
- 类目专属字段（扩展字段，原属性分类 + 商品属性）
  - 按分组分块，标题为「分组名 · 一级名称专属」；块内同列结构表格
  - 字段为扁平结构，不支持多级属性树；类型为文本 / 多行文本 / 下拉 / 单选 / 多选 / 数字 / 整数 / 开关 / 日期；说明优先展示 tip，选项类可汇总选项
  - 操作：编辑、删除；分组操作：编辑分组、删除分组；顶部可「新增分组」「新增扩展字段」
  - 对不上分组的归入「未分类 · 一级名称专属」
  - 新增 / 编辑扩展字段：所属分组、字段名称、标识、类型、排序、必填、说明；类型为下拉 / 单选 / 多选时填写选项（每行一个）
  - 删除分组：若仍有扩展字段引用，提示「该分组下已有扩展字段，请先调整后再删除」
  - 二至四级不再维护扩展字段定义；原「商品属性」多级逻辑已去除

#### 1.2.8 已绑定商品

- 仅四级分类展示该页签
- 顶部：共 N 个商品
- 商品卡片：商品图片、商品名称、商品编码
- 无数据：暂无绑定商品；删除分类前需解绑全部商品
- 本页只查看已绑定商品，不在本页绑定或解绑；解绑完成后，才允许删除对应分类
